કેવી રીતે વાપરવી, Google AI Studio બંધ રાખીને એપ કેવી રીતે ચલાવવી,
અને iPhone, Android, Windows, Mac તેમજ Play Store / App Store પર
કેવી રીતે મૂકવી તેની સંપૂર્ણ માહિતી આપેલી છે.

--------------------------------------------------------------------
૧. RAA'S DIARY એપમાં કયા-કયા મુખ્ય ફીચર્સ છે?
--------------------------------------------------------------------
1) Home (હોમ ડેશબોર્ડ):
   - અહીં આજના દિવસનો સ્કોર (%), કેટલા કામ (Tasks) પૂરા થયા, કેટલું
     પાણી (Water) પીધું, ફોકસ ટાઇમ, અને આજનું ટાઇમટેબલ એક જ સ્ક્રીન
     પર દેખાય છે.
   - "Daily Affirmation" કાર્ડમાં રોજનો એક સકારાત્મક સુવિચાર (English
     અને ગુજરાતી બંનેમાં) મળે છે. તેને કોપી કરી શકાય, સાંભળી શકાય
     (Voice), અને ૧ ક્લિકમાં તમારી ડાયરીમાં સેવ કરી શકાય છે.
   - "Master Brain" કાર્ડ તમારા આખા દિવસનું લાઇવ એનાલિસિસ કરે છે અને
     ૧ ક્લિકમાં બાકી કામ, પાણી અને ફોકસ સેટ કરી આપે છે.

2) My Routine (મારી દિનચર્યા):
   - સવારથી રાત સુધીનું તમારું રોજનું ટાઇમટેબલ અહીં બનાવી શકાય છે.
   - જે કામ પૂરું થાય તેની સામે ટિક (✓) કરો.
   - "Reschedule" બટનથી કોઈ પણ બ્લોકનો સમય સરળતાથી બદલી શકાય છે.

3) Tasks (કામની યાદી):
   - તમારા નાના-મોટા બધા કામ, તેની તારીખ, સમય અને Priority (Urgent,
     High, Medium, Low) અહીં લખી શકાય છે.
   - જો કોઈ જૂનું કામ રહી ગયું હોય તો તે ડિલીટ થતું નથી — "Overdue
     Recovery" માં સચવાયેલું રહે છે જેથી તમે તેને આજે શિફ્ટ કરી શકો.

4) Trackers & Water (પાણી અને હેલ્થ ટ્રેકર):
   - રોજ કેટલું પાણી પીધું (+100ml, +250ml, +500ml) તે ૧ ક્લિકમાં નોંધો.
   - સાથે ઊંઘ (Sleep), કસરત (Exercise), પગલાં (Steps), ખોરાક (Food),
     મૂડ (Mood), એનર્જી (Energy) અને તમારા પોતાના Custom Trackers બનાવો.

5) Focus Mode (પોમોડોરો ફોકસ ટાઇમર):
   - ભણવા કે ઓફિસના કામ માટે 25 મિનિટનો ફોકસ ટાઇમર ચાલુ કરો.
   - Start, Pause, Reset અને Short/Long Break ની સુવિધા છે.

6) Calendar (કેલેન્ડર):
   - મહિના, અઠવાડિયા કે દિવસ પ્રમાણે તમારા બધા ઇવેન્ટ્સ અને કામ જુઓ.
   - કોઈ પણ તારીખ પર ક્લિક કરીને તે દિવસનો આખો ઇતિહાસ જોઈ શકાય છે.

7) Alarms (સ્માર્ટ એલાર્મ - ૨૫ મધુર ટોન સાથે):
   - સવારે ઉઠવાનું એલાર્મ, દર કલાકે પાણી પીવાનું એલાર્મ, અને ખાસ
     કામના રિમાઇન્ડર અહીં સેટ કરો.
   - તેમાં ૨૫ અલગ-અલગ સુપર ક્વોલિટી અવાજો (Crystal Bell, Zen, Harp,
     Chime, Ocean, Birdsong, Piano, Rain, Cosmic, Breeze વગેરે) આપેલા છે.
   - કોઈ વધારાની mp3 ડાઉનલોડ કર્યા વિના Web Audio API થી આપોઆપ વાગે છે.
   - iOS 27 લિક્વિડ ગ્લાસ એનિમેશન અને વાઇબ્રન્ટ સ્પ્રિંગ ઇફેક્ટ્સ
     સાથે એલાર્મ સ્ક્રીન રિંગ થાય છે.

8) Notes & Diary (નોંધ અને ડાયરી):
   - "કેટલા વાગે શું કર્યું" તેની સમય સાથેની ડાયરી લખો.
   - રોજની સારી વાતો (Daily Journal) અને મહત્વની નોટ્સ સેવ કરો.

9) Master Brain & AURAA AI (તમારો પર્સનલ AI આસિસ્ટન્ટ):
   - AURAA AI ને ગુજરાતી કે અંગ્રેજીમાં પૂછો:
     "મારા આજના બાકી કામનો પ્લાન બનાવો" અથવા "સવારે ૭ વાગ્યાનું એલાર્મ
     મૂકો" — તે સીધું એક્શન બટન બનાવી આપશે.
   - Master Brain તમારા ૪ પિલર (કામ, પાણી, ફોકસ, નિયમિતતા) નો
     લાઇવ સ્કોર બતાવે છે અને ૧ ક્લિકમાં સુધારા કરી આપે છે.

10) History & Backup (ઇતિહાસ અને બેકઅપ):
    - જૂના દિવસોનો બધો રેકોર્ડ અહીં સુરક્ષિત રહે છે.
    - Settings માંથી JSON બેકઅપ અથવા Calendar (.ics) ફાઇલ ડાઉનલોડ
      કરી શકાય છે.

--------------------------------------------------------------------
૨. GOOGLE AI STUDIO બંધ રાખીને એપ કેવી રીતે વાપરવી?
--------------------------------------------------------------------
તમારે રોજ એપ વાપરવા માટે Google AI Studio ખોલીને રાખવાની જરૂર નથી:

પગલું ૧: Google AI Studio માં ઉપર જમણી બાજુ "Deploy" અથવા "Share /
        Publish App" બટન પર ક્લિક કરીને તમારી એપને લાઇવ (Cloud Run)
        પર પબ્લિશ કરી દો.
પગલું ૨: પબ્લિશ કર્યા પછી તમને એક કાયમી HTTPS લિંક (URL) મળશે
        (જેમ કે https://your-app-name.run.app અથવા તમારું Custom Domain).
પગલું ૩: હવે તમે Google AI Studio સંપૂર્ણપણે બંધ કરી શકો છો!
પગલું ૪: એ કાયમી લિંકને તમારા iPhone, Android, Windows PC કે Mac માં
        ખોલીને "Install App" કરી લો — પછી તે સાચી એપની જેમ સીધી
        Home Screen / Desktop પરથી જ ખુલશે.

નોંધ: ફક્ત Development (ais-dev-...) લિંક AI Studio સેશન ચાલુ હોય
ત્યાં સુધી ચાલે છે. ૨૪x૭ કાયમી વાપરવા માટે હંમેશા "Deploy / Publish"
કરેલી લાઇવ લિંક જ વાપરો.

--------------------------------------------------------------------
૩. દરેક ડિવાઇસમાં એપ કેવી રીતે ઇન્સ્ટોલ કરવી?
--------------------------------------------------------------------
[A] iPhone / iPad (iOS):
    ૧. તમારી લાઇવ એપ લિંક Apple Safari બ્રાઉઝરમાં ખોલો.
    ૨. નીચે વચ્ચે રહેલું Share (ચોરસમાં ઉપર તીર □↑) બટન દબાવો.
    ૩. નીચે સ્ક્રોલ કરી "Add to Home Screen" પસંદ કરો.
    ૪. ઉપર જમણી બાજુ "Add" દબાવો — હોમ સ્ક્રીન પર R+ આઇકન આવી જશે!

[B] Android Phone:
    ૧. લાઇવ એપ લિંક Google Chrome માં ખોલો.
    ૨. ઉપર જમણી બાજુ ૩ ટપકાં (⋮) દબાવો અથવા એપમાં "Download App"
       પર ક્લિક કરો.
    ૩. "Install app" દબાવો — Android ફોનમાં સીધી એપ ઇન્સ્ટોલ થઈ જશે.

[C] Windows PC (વિન્ડોઝ કમ્પ્યુટર):
    ૧. લાઇવ એપ લિંક Google Chrome અથવા Microsoft Edge માં ખોલો.
    ૨. ઉપર એડ્રેસ બારમાં જમણી બાજુ Install (⊕) આઇકન પર ક્લિક કરો.
    ૩. "Install" દબાવો — આ એપ ડેસ્કટોપ અને Taskbar પર અસલી PC એપની
       જેમ અલગ વિન્ડોમાં ચાલશે.

[D] Mac (MacBook / iMac - macOS):
    ૧. Apple Safari માં લાઇવ એપ લિંક ખોલો.
    ૨. ઉપર મેનૂમાં File → "Add to Dock..." પર ક્લિક કરો.
       (અથવા Chrome માં એડ્રેસ બારનું Install ⊕ બટન દબાવો).
    ૩. તમારા Mac ના Dock માં Raa's Diary નો આઇકન આવી જશે.

--------------------------------------------------------------------
૪. GOOGLE PLAY STORE અને APPLE APP STORE પર કેવી રીતે મૂકવી?
--------------------------------------------------------------------
આ પ્રોજેક્ટમાં પહેલેથી જ Web App Manifest, Maskable Icons (512x512),
iOS Apple Touch Icon (180x180) અને "capacitor.config.json" તૈયાર
કરીને મૂકેલા છે.

[A] Google Play Store (Android .AAB / .APK માટે):
    રીત ૧ (સૌથી સરળ - PWABuilder):
      ૧. પહેલાં એપને લાઇવ HTTPS લિંક પર Deploy કરો.
      ૨. https://www.pwabuilder.com ખોલી તમારી લાઇવ લિંક પેસ્ટ કરો.
      ૩. "Package for Stores" → Android પસંદ કરો અને Google Play
         માટેની .AAB ફાઇલ ડાઉનલોડ કરો.
      ૪. Google Play Console (play.google.com/console) માં અકાઉન્ટ
         બનાવી .AAB અપલોડ કરી પબ્લિશ કરો.

    રીત ૨ (Capacitor દ્વારા Full Native Android App):
      ૧. પ્રોજેક્ટ તમારા PC માં ડાઉનલોડ કરો (Download ZIP / GitHub).
      ૨. ટર્મિનલમાં ચલાવો:
         npm install
         npm run build
         npm install @capacitor/core @capacitor/cli @capacitor/android
         npx cap add android
         npx cap open android
      ૩. Android Studio માંથી Signed App Bundle (.aab) બનાવીને
         Google Play Store પર અપલોડ કરો.

[B] Apple App Store (iPhone / iPad .IPA માટે):
    ૧. Mac કમ્પ્યુટરમાં Xcode ઇન્સ્ટોલ હોવું જરૂરી છે અને Apple
       Developer Account (developer.apple.com) જોઈએ.
    ૨. પ્રોજેક્ટમાં નીચેના કમાન્ડ ચલાવો:
       npm install
       npm run build
       npm install @capacitor/core @capacitor/cli @capacitor/ios
       npx cap add ios
       npx cap open ios
       (અથવા PWABuilder માંથી પણ iOS Xcode પ્રોજેક્ટ બનાવી શકાય છે).
    ૩. Xcode માં તમારી Apple Team / Bundle ID (com.raasdiary.app)
       સિલેક્ટ કરી Product → Archive → Distribute App → App Store
       Connect પર સબમિટ કરો.
